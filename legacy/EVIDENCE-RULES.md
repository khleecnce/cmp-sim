# 근거 충돌 판정 규칙 (EVIDENCE-RULES.md) — 2026-09-11

사용자 지시 원문:
> "상충되는 데이터가 있으면 **더 근거 있는 데이터가 뭔지 판단해서 그쪽으로 진행**해."

## 왜 이 파일이 생겼나

지금까지 충돌이 나면 노트에 "정면충돌", "상호모순", "미반영"으로 **기록만 하고 멈췄다**.
정직하긴 했지만 진행이 안 됐다 — κ(입경)는 5회차째 같은 자리에서 돌고 있다.
정직성은 유지하되, **판정하고 앞으로 간다**. 판정은 취향이 아니라 아래 서열로 한다.

## 근거 서열 (위가 강하다)

| 등급 | 종류 | 판정 무게 |
|---|---|---|
| **E1** | **대상 계에서의 직접 실측 + 교란변수 통제** (한 변수만 스윕, n≥5) | 최강. 이론과 충돌하면 **실측이 이긴다** |
| **E2** | 1차 문헌의 **폐형식 유도 + 같은 막질/화학계에서 저자 본인 검증** | 강 |
| **E3** | 대상 계 실측이지만 **교란 있음**(입경과 형상이 함께 변함 등) | 중. 교란 분리 전까지 단독 채택 금지 |
| **E4** | 1차 유도지만 **다른 막질/계에서 검증된 것을 전이**(oxide→Cu 등) | 중하. 방향만 채택, 크기는 미채택 |
| **E5** | 2차 인용(리뷰·초록·스니펫), 원문 미확보 | 약. 단독 채택 금지 |
| **E6** | 추정·업계 관행·LLM 사전지식 | **채택 금지** |

## 판정 절차 (충돌을 만나면 이 순서로)

1. **양측 등급을 매긴다.** 등급이 다르면 높은 쪽을 채택하고 끝. 노트에 "E3 vs E1 → E1 채택"으로 남긴다.
2. **등급이 같으면 아래 순서로 깬다.**
   - ① **계 근접도** — 대상 막질·연마입자·화학이 더 가까운 쪽
   - ② **n과 스윕 폭** — 표본 수, 변수 범위가 넓은 쪽
   - ③ **교란 통제** — 한 변수만 움직인 쪽
   - ④ **재현 가능성** — 원문 수치를 우리가 python verify로 재현한 쪽
3. **그래도 안 갈리면 스코프를 쪼갠다.** "둘 다 맞되 레짐이 다르다"가 대개 정답이다
   (예: 입경-MRR이 oxide는 peak형, Cu는 valley형 → 팩별 분기. 하나의 지수로 통일하지 마라).
4. **"효과 없음(null)"도 결론이다.** 교란을 걷어낸 부분집합에서 유의하지 않으면, 그건 미완이
   아니라 **"이 계에서 이 변수는 지배인자가 아니다"라는 검증된 지식**이다. `status=modeled`,
   `confidence=literature`로 기록하고 다음으로 간다. 무한 재시도 금지.

## 금지

- 충돌을 평균내지 마라. 두 상반된 지수의 산술평균은 어느 문헌도 지지하지 않는 창작이다.
- 백테스트 ρ가 높아진다는 이유로 약한 근거를 채택하지 마라. 그건 데이터 스누핑이다.
- 판정을 미루고 "미반영"으로 남기는 것은 **3회차까지만** 허용. 3회차를 넘으면 §절차 4(null 결론)
  또는 스코프 축소 중 하나로 **반드시 종결**하고 사용자에게 보고한다.
