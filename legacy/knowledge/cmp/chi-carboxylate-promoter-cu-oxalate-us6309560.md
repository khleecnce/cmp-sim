## 1. 질문

판정#73은 `jani2025_cu_rsm_composition_heldout`(n=13)의 ρ가 **−0.349**로 음수인 —
즉 모델이 순위를 뒤집는 — 원인을 옥살산 미모델링으로 지목했다. 그 데이터셋의
옥살산은 0.02~0.08 M로 3배 넘게 움직이는데 모델에는 받을 통로가 없었다.

판정#73이 이 축을 그때 바로 배선하지 않은 이유는 명확하다: 유일한 정량 근거가
**그 held-out 자신**(Jani RSM 회귀)이라 거기서 계수를 뽑으면 자기채점이 된다.
따라서 이번 회차의 과제는 **독립 1차 문헌에서 배수 관계를 확보하는 것**이었다.

## 2. 1차 출처 (독립 — held-out과 다른 문헌)

Vlasta Brusic Kaufman, Rodney C. Kistler, Shumin Wang (Cabot Corporation),
"Chemical mechanical polishing slurry useful for copper substrates",
**US6309560B1**, 등록 2001-10-30(우선일 1996-12-09).
https://patents.google.com/patent/US6309560B1/en — 전문 확보, TABLE 1 인쇄값.

공정(TABLE 1 전 조건 고정): Strasbaugh 폴리셔, **3 psi**, table **45 rpm**,
spindle **50 rpm**, 알루미나 연마입자 **5 wt% 고정**, 착화제 = 옥살산암모늄
((NH₄)₂C₂O₄), 습윤제 TRITON DF-16.

## 3. 결과 — 농도를 올릴수록 **단조 증가**, 포화형

TABLE 1의 6행 중 **옥살산만 바뀌고 나머지가 고정인 통제쌍**은 2건이다(전수 대조):

| 통제쌍 | 고정 조건 | 옥살산암모늄 | Cu RR (nm/min) | 배수 |
|---|---|---|---|---|
| 1행 → 2행 | H₂O₂ **7%**, BTA 0, 습윤제 **50 ppm** | 0 → 0.5 wt% | 21.7 → 278.0 | **12.81** |
| 3행 → 4행 | H₂O₂ **11%**, BTA 0, 습윤제 **10 ppm** | 0.5 → 1.0 wt% | 251.7 → 402.9 | **1.6007** |

두 쌍의 H₂O₂·습윤제 수준이 서로 다르다 — 이것이 이 노트의 가장 큰 한계다(§6).

**함수형**(멱 + 기계 바닥):
```
g(C) = φ + (1−φ)·(C/C_anchor)^m ,  f(C) = g(C)/g(C_ref)
```
- φ는 착화제 0에서의 잔여 배수(순수 기계 성분). 없으면 C→0에서 0으로 붕괴해
  물리가 아니라 특이점이 된다. φ = 21.7/278.0 = **0.078058** (1행→2행 쌍).
- C_anchor = 0.5 wt% = **0.040290 M** ((NH₄)₂C₂O₄ MW 124.10, 밀도 1.0 g/mL 근사).
- m = log₂((1.6007 − φ)/(1 − φ)) = **0.7238** (3행→4행 쌍). m<1 = 포화형.

## 4. 정량 재현 (verify)

```python verify
import math

# ── US6309560B1 TABLE 1 인쇄값 (nm/min) ──
A0, A1 = 21.7, 278.0      # 7% H2O2, 50ppm 습윤제, BTA 0: 옥살산 0 → 0.5 wt%
B1, B2 = 251.7, 402.9     # 11% H2O2, 10ppm 습윤제, BTA 0: 옥살산 0.5 → 1.0 wt%
MW_AMMOX = 124.10         # (NH4)2C2O4 무수물 g/mol
def M(wt_pct):            # wt% -> mol/L (밀도 1.0 g/mL 근사)
    return wt_pct * 10.0 / MW_AMMOX

C_anchor = M(0.5)
assert abs(C_anchor - 0.040290) < 1e-5, C_anchor
assert abs(M(1.0) - 0.080580) < 1e-5

phi = A0 / A1
assert abs(phi - 0.078058) < 1e-5, phi

r = B2 / B1
assert abs(r - 1.6007) < 1e-4, r
m = math.log((r - phi) / (1.0 - phi), 2.0)
assert abs(m - 0.7238) < 1e-4, m

def g(C):
    return phi + (1.0 - phi) * (C / C_anchor) ** m

# 두 통제쌍을 정확히 통과한다(2점 2미지수라 잔차 0 — 이건 검증이 아니라 항등이다)
assert abs(g(0.0) / g(C_anchor) - A0 / A1) < 1e-9
assert abs(g(M(1.0)) / g(M(0.5)) - r) < 1e-9

# ── 독립 교차확인: Jani 2025 RSM (적합에 쓰지 않은 별개 문헌·별개 계) ──
# doi:10.1149/2162-8777/adc59e 회귀 표: Intercept 1044.65, [oxalic acid] +536.63
# 코드화 -1..+1 이 각각 0.02 / 0.08 M 이므로 두 끝점의 예상비:
jani_ratio = (1044.65 + 536.63) / (1044.65 - 536.63)
model_ratio = g(0.08) / g(0.02)
assert abs(jani_ratio - 3.113) < 1e-3, jani_ratio
assert abs(model_ratio - 2.515) < 1e-3, model_ratio
# **19.2% 낮다.** 방향과 오더는 맞고 크기는 어긋난다 — 맞는 척 꾸미지 않는다.
dev = 100.0 * (model_ratio - jani_ratio) / jani_ratio
assert -25.0 < dev < -15.0, dev
assert abs(dev + 19.2) < 0.2, dev

# ── 같은 특허 TABLE 4 (교란 미분리) — 이 항이 재현하지 못한다 ──
# urea-peroxide 5.65%, 옥살산 0 → 1 wt%: 9.5 → 796.3 (비 83.8)
# 단, 습윤제가 0 → 50 ppm 으로 **함께** 바뀐다(TABLE 1 쌍은 습윤제 고정).
t4_meas = 796.3 / 9.5
t4_model = g(M(1.0)) / g(0.0)
assert abs(t4_meas - 83.82) < 0.02, t4_meas
assert abs(t4_model - 20.51) < 0.02, t4_model
assert t4_model < t4_meas / 3.0   # 4.1배 과소 — 교란(습윤제)이 분리되지 않은 쌍이다
print("PASS: phi=%.6f m=%.4f | Jani 교차 %.1f%% | TABLE4 %.1f배 미재현"
      % (phi, m, dev, t4_meas / t4_model))
```

## 5. 새로 도출한 지식 — 왜 χ이고 왜 ψ가 아닌가

같은 팩의 글리신은 **ψ**(억제, 판정#72)이고 옥살산은 **χ**(촉진)다. 같은 "착화제"
라는 이름을 달고 정반대 팩터에 사는 것은 임의 분리가 아니다:

- Jani 2025 회귀가 **같은 표에서** [oxalic acid] = +536.63 (p=1.7e-7),
  [glycine] = −440.91 (p=4.1e-7)로 갈라놨다 — 둘 다 유의하고 부호가 반대다.
- 판정#45가 이미 "둘을 하나의 레짐으로 묶은 것은 과도한 일반화"라고 판정했고,
  판정#47이 그 판정을 종 게이트(`*_species` 키)로 코드에 넣었다.
- 이 노트는 그 종 분리를 **한 단계 더 밀어** 팩터 자체를 나눈다. 두 축을 한
  팩터에서 곱하면 사용자가 "촉진/억제 분리"를 못 본다 — `_f_chi`/`_f_psi`의
  설계 계약(χ=촉진, ψ=억제)이 그것을 금지한다.

부호가 갈리는 **메커니즘 가설**(미검증): 옥살산은 산화된 Cu(II)를 용해성
착물로 제거해 부동태막을 얇게 유지하는 반면, 글리신은 Cu–글리신 착물이 표면에
잔류해 흡착 보호층으로 작동한다(Jani 원문 결론: "glycine effectively functions as
an inhibitor rather than a dissolution promoter"). 이 노트는 **방향을 실측으로
확정**했을 뿐 메커니즘을 증명하지 않았다.

## 6. 정직성 표지 — 이 값을 어디까지 믿나

1. **φ와 m이 서로 다른 계열에서 나왔다.** φ는 7% H₂O₂ / 습윤제 50 ppm 계열,
   m은 11% H₂O₂ / 습윤제 10 ppm 계열이다. 각 계열에 옥살산 3수준이 없어
   (φ, m)을 한 계열에서 동시에 풀 수 없었다. 습윤제는 이 엔진에 미모델링 축이다.
2. **Jani 교차확인이 19.2% 낮다** — 위 verify가 assert로 고정한 사실이다.
   계가 다르다(알루미나/옥살산암모늄/pH 7.5 자연 vs 실리카/옥살산/pH 3.0).
   두 값을 평균내지 않았다(EVIDENCE-RULES: 상반된 두 지수를 평균내지 마라).
   근거 서열상 이 항은 E3(교란 있는 실측), Jani 회귀는 E2(동일계 폐형식)이나
   Jani는 held-out이라 계수 추출이 금지돼 있어 **독립 검증자로만** 쓴다.
3. **같은 특허 TABLE 4를 4.1배 과소 예측한다.** 그 쌍은 습윤제가 함께 변해
   교란이 분리되지 않았으므로 채택하지 않았지만, 숨기지 않고 verify에 박았다.
   "TABLE 1이 옳고 TABLE 4가 틀렸다"가 아니라 **TABLE 4로는 이 축을 식별할 수
   없다**는 뜻이다.
4. **옥살산암모늄(염) ≠ 옥살산(산).** 활성종이 옥살레이트 음이온이면 같지만,
   암모늄 자신의 Cu 착화 기여는 분리되지 않았다(특허 본문이 고pH에서
   Cu(NH₃)ₓ 형성을 언급한다). 이 전이가 등급을 estimated에 묶는 세 번째 이유다.
5. 밀도 1.0 g/mL 근사로 wt% → mol/L 환산했다 — `chelator_M`과 동일한 가정이다.

## 7. 백테스트 효과 (실행 결과)

`jani2025_cu_rsm_composition_heldout`(n=13, held-out, 이 항의 적합에 **미사용**):

| | ρ | p(순열) | 판정 |
|---|---|---|---|
| 배선 전 | **−0.349** | 0.877 | 모델이 순위를 뒤집음 |
| 배선 후 | **+0.302** | 0.158 | 방향 교정, 아직 비유의 |

**부호가 뒤집혔다** — 판정#73이 이 데이터셋의 음수 ρ 원인으로 지목한 것이
실제로 이 축이었음을 독립 문헌에서 뽑은 계수가 확인해 준다. 다만 p=0.158로
여전히 비유의라 C4 게이트에는 들어가지 못한다(유의 평균 ρ 0.9566 불변).
**남은 잔차**: DOSS(계면활성제) 미연결, 습윤제 축 미모델링, 옥살산×글리신
교호작용(같은 회귀 −289.83, p=4.0e-5)이 미모델링이다.

⚠ MAPE는 848% → 11730%로 **악화**했다. 이 팩의 Kp가 옥살산 0 조성에서
역산됐는데 이 데이터셋은 전 조건이 0.02 M 이상이라 촉진 배수가 20배 가까이
곱해지기 때문이다. 이 데이터셋은 원래 **순위 전용**으로 선언돼 있고(파일
notes), 절대값 교정은 이 팩을 옥살산 함유 조성으로 재캘리브레이션해야 풀린다 —
이번 회차 범위 밖이고, held-out에서 Kp를 역산하면 자기채점이다.
