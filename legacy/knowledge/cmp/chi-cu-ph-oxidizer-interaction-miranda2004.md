## 1. 무엇을 하려 했나

판정#73은 C4를 막는 유일한 원인이 `tw202115224a`(n=18) 하나라고 확정했고, 그 데이터셋
안에서는 더 뽑을 게 없다(입자 형상축은 판정#68이 이미 자기채점 회피로 종결). 남은 길은
**새 held-out 확보**뿐이다. 그래서 `cu_h2o2_bta` 계의 조성축이 움직이는 공개 DOE를 찾았다.

## 2. 1차 출처 (오픈액세스, 코퍼스 밖 신규)

Chemical Mechanical Planarization of Electroplated Copper", **2004 IEEE Workshop on
Microelectronics and Electron Devices (WMED)**, 2004. **doi:10.1109/WMED.2004.1297359**
원문(OA): https://scholarworks.boisestate.edu/cgi/viewcontent.cgi?article=1025&context=electrical_facpubs
확보 텍스트: `papers/miranda2004-wmed-cu-cmp-ph-h2o2.txt`

> 본문 텍스트는 추출기를 통해 받았고, 아래 표 수치는 원문 TABLE 3 인쇄값이다. PDF 바이너리

설계: 2² 완전요인 × 3반복 = 12 run. **pH 4/8 × H₂O₂ 1.5/3.5 %**. 나머지 전부 고정
(Cabot 5001 알루미나 슬러리, EPAD-A100 패드, Strasbaugh 6DS-SP, 4 psi, 60/60 rpm,
200 mL/min, 60 s, 4인치 전해도금 Cu).

| 조건 | Cu RR (Å/min) | nm/min |
|---|---|---|
| pH 4, H₂O₂ 1.5 % | 1953 | 195.3 |
| pH 4, H₂O₂ 3.5 % | 2908 | 290.8 |
| pH 8, H₂O₂ 1.5 % | 1743 | 174.3 |
| pH 8, H₂O₂ 3.5 % |  243 |  24.3 |

원문 ANOVA: pH 주효과 p=0.0021, **pH×H₂O₂ 교호작용 p=0.0207**, H₂O₂ 단독 p=0.588(비유의),
보정 R²=0.69.

## 3. 핵심 — 산화제 효과의 **부호가 pH에 따라 뒤집힌다**

같은 재료계·같은 장비에서 H₂O₂를 1.5→3.5 %로 올렸을 때:

- **pH 4(산성)**: 195.3 → 290.8 nm/min = **×1.489 (+48.9 %)** — 촉진
- **pH 8(알칼리)**: 174.3 → 24.3 nm/min = **×0.1394 (−86.1 %)** — 급격한 억제

로그공간 교호작용 대비 = ln(1.489) − ln(0.1394) = **2.368** → 두 pH에서 산화제 민감도가
**10.7배** 갈린다. 이것은 정량 편차가 아니라 **정성적 부호 반전**이다.

메커니즘(원문 해석, Pourbaix 기반): 산성에서는 Cu²⁺가 생겨 제거가 쉬워지고, 알칼리 +
고농도 H₂O₂에서는 **단단한 CuO 부동태막**이 형성되어 제거를 막는다. 원문이 인용한
Wei et al.: pH 8에서 0.06 % H₂O₂ → Cu₂O, 2.5 % H₂O₂ → CuO.

이 부호 반전은 판정#41·#45·#47이 **착화제 종**을 축으로 찾아낸 같은 현상의 **pH 축 버전**이다
— 즉 `oxidizer_passivation_K`(억제형)와 `oxidizer_acid_chelator_K`(촉진형) 사이의 분기는
착화제만으로 결정되지 않는다.

## 4. 모델을 돌린 결과 — 예측이 pH에 **전혀 반응하지 않았다**

백테스트 실측(직접 실행):

| 조건 | 실측 nm/min | 예측 nm/min |
|---|---|---|
| pH 4, 1.5 % | 195.3 | 1069.60 |
| pH 4, 3.5 % | 290.8 |  662.19 |
| pH 8, 1.5 % | 174.3 | **1069.60** |
| pH 8, 3.5 % |  24.3 | **662.19** |

ρ = **0.000**, τ = 0.000, p = 0.5417, MAPE 928.5 %, 계통편향 0.17배.

정량 재현 대조(문헌값 출처: Miranda 2004 WMED, doi:10.1109/WMED.2004.1297359 TABLE 3):
문헌값 195.3 / 290.8 / 174.3 / 24.3 nm/min 대비 예측 1069.6 / 662.2 / 1069.6 / 662.2 nm/min.
pH 8 · H2O2 3.5 % 조건에서 문헌값(doi:10.1109/WMED.2004.1297359) 24.3 nm/min 대비 예측이
27.2배 과대하고, 가장 잘 맞는 pH 4 · 3.5 % 조건도 같은 출처의 290.8 nm/min 대비 2.28배
어긋난다. §6 verify 블록이 이 네 쌍을 assert 로 고정한다. 맞는 척 꾸미지 않고 그대로 적는다.

**pH 4와 pH 8의 예측이 소수점까지 동일하다.** 이것은 수치 오차가 아니라 pH 축이 완전히
침묵했다는 뜻이다.

원인은 버그가 아니라 **코드가 스스로 선언한 게이트**다(`sim/factors.py:1152~1176`):

```
레짐 1 (산성 × 억제제 유)   k=0.1428   US20080090500A1 T4, 12점 R²=0.954  → 활성
레짐 2 (알칼리 × 억제제 무) k=0.3329   US9200180B2 T4,     5점 R²=0.997   → 활성
레짐 3 (산성 × 억제제 무)   관측 없음 → 항 비활성
레짐 4 (알칼리 × 억제제 유) 관측 없음 → 항 비활성
```

`cu_h2o2_bta`는 `inhibitor_mM = 1.0`을 선언하므로 **억제제 유**다. 따라서 pH 8 조건은
**레짐 4**로 떨어지고 pH 항이 꺼진다. 그리고 pH 4 조건은 레짐 1이지만 팩의 `ph_ref = 4.0`
이라 배수가 항등적으로 1.0이다. 결과적으로 네 조건 모두 pH 항 = 1.0 → 예측이 H₂O₂에만
반응한다(1.5 % > 3.5 %는 억제형 `oxidizer_passivation_K` 때문).

즉 **이 데이터셋은 모델의 성능이 아니라 모델이 선언한 공백(레짐 4)을 정면으로 비춘다.**
ρ=0은 "모델이 틀렸다"가 아니라 "모델이 답하기를 거부한 구간을 채점했다"에 가깝다 —
단, 거부한 사실 자체를 held-out이 드러냈다는 점에서 이 0은 정보다.

## 5. 왜 이 데이터로 레짐 4를 채우지 않는가 (E-등급 판정)

유혹: pH 4/8 두 점이 있으니 알칼리 k를 역산해 레짐 4를 열 수 있어 보인다. **하지 않는다.**

1. **억제제 유무를 알 수 없다.** Cabot 5001은 상용 슬러리이고 원문은 첨가제 조성을
   공개하지 않는다("contains alumina based abrasives, batch processed to a pH of ~8").
   레짐 4의 정의 자체가 "억제제 존재"인데, 이 데이터가 레짐 4인지 레짐 2인지 **확정할 수 없다.**
   → 근거 등급 **E4(타계 전이 유도)** 이하. 레짐 계수는 E2 이상을 요구한다.
2. **pH 2점으로는 k를 식별할 수 없다.** 2점 1미지수는 잔차 0이라 항등이지 적합이 아니다
   (판정#75가 같은 이유로 φ·m을 각각 다른 통제쌍에서 뽑았다).
3. **교호작용이 있는데 주효과만 뽑으면 그 계수는 데이터셋 지문이 된다.** 원문 스스로
   pH×H₂O₂ p=0.0207로 교호작용을 확인했다. 두 축이 얽힌 4점에서 pH 계수 하나를 뽑으면
   H₂O₂ 효과가 그 안에 접혀 들어간다.

**판정: 계수를 만들지 않고 데이터셋만 등록한다(E4 → 채택 금지, 관측 기록은 채택).**
이는 판정#68(입자 형상 — 진짜 효과지만 유일 출처가 held-out 자신이라 배선 안 함)과 같은 형태다.

## 6. 정량 재현 (verify)

```python verify
import math

# ── Miranda 2004 WMED TABLE 3 인쇄값 (Å/min) ──
RR = {(4, 1.5): 1953.0, (4, 3.5): 2908.0,
      (8, 1.5): 1743.0, (8, 3.5):  243.0}

# nm/min 환산 (÷10) — 데이터셋 YAML에 들어간 값과 일치해야 한다
assert abs(RR[(4, 1.5)] / 10.0 - 195.3) < 1e-9
assert abs(RR[(4, 3.5)] / 10.0 - 290.8) < 1e-9
assert abs(RR[(8, 1.5)] / 10.0 - 174.3) < 1e-9
assert abs(RR[(8, 3.5)] / 10.0 -  24.3) < 1e-9

# ── §3 부호 반전 ──
r_acid = RR[(4, 3.5)] / RR[(4, 1.5)]
r_alk  = RR[(8, 3.5)] / RR[(8, 1.5)]
assert abs(r_acid - 1.4890) < 1e-3, r_acid       # 산성: 촉진 +48.9%
assert abs(r_alk  - 0.13941) < 1e-4, r_alk       # 알칼리: 억제 -86.1%
assert r_acid > 1.0 > r_alk                      # 부호가 갈린다 — 정성적 반전

# 로그공간 교호작용 대비 = 두 pH에서 산화제 민감도 차이
contrast = math.log(r_acid) - math.log(r_alk)
assert abs(contrast - 2.3684) < 1e-3, contrast
assert abs(math.exp(contrast) - 10.681) < 1e-2   # 10.7배

# ── §4 모델이 pH에 반응하지 않았음을 재현 ──
# 팩 cu_h2o2_bta 는 inhibitor_mM=1.0 (억제제 유) 이므로
# sim/factors.py 의 레짐 판정에서 pH 8 은 레짐 4(관측 없음) -> 항 비활성.
VALLEY_PH = 6.25
def ph_term_active(ph, has_inhibitor):
    alkaline = ph > VALLEY_PH
    if alkaline and has_inhibitor:
        return False          # 레짐 4 — 코드가 선언한 공백
    if (not alkaline) and (not has_inhibitor):
        return False          # 레짐 3 — 역시 공백
    return True
assert ph_term_active(4.0, True) is True      # 레짐 1
assert ph_term_active(8.0, True) is False     # 레짐 4 -> 침묵
assert ph_term_active(8.0, False) is True     # 레짐 2

# 레짐 1이라도 ph_ref 와 같으면 배수는 항등적 1.0 (이중계상 방지 정의)
k_acid, ph_ref = 0.1428, 4.0
assert abs(math.exp(-k_acid * (4.0 - ph_ref)) - 1.0) < 1e-12
# -> 네 조건 전부 pH 배수 1.0 => pH 4 와 pH 8 예측이 동일해진다

# 백테스트가 실제로 낸 예측값 (직접 실행해 옮김)
pred = {(4, 1.5): 1069.6035869782888, (4, 3.5): 662.1884867892296,
        (8, 1.5): 1069.6035869782888, (8, 3.5): 662.1884867892296}
assert pred[(4, 1.5)] == pred[(8, 1.5)]       # pH 축 침묵 — 소수점까지 동일
assert pred[(4, 3.5)] == pred[(8, 3.5)]
# 그 결과 Spearman rho = 0 (실측 순위 2>1>3>4 vs 예측 1=3>2=4)
```

## 7. 새로 도출한 지식

1. **Cu 산화제 항의 부호는 착화제만으로 정해지지 않는다 — pH도 스위치다.** 판정#41~#47은
   착화제 종(옥살산 vs 글리신)으로 부호를 갈랐는데, 이 데이터는 **착화제를 고정한 채 pH만으로**
   같은 반전을 만든다. 현행 구현은 팩당 산화제 항의 부호를 하나만 가지므로 구조적으로
   이 거동을 표현할 수 없다. → `sim/chemistry.py::_oxidizer_term`의 레짐 게이트에
   **pH 조건을 추가해야 한다**(현재는 `slurry_ph < 6` AND `chelator_M > 0`으로 촉진형만 분기).
2. **레짐 4(알칼리 × 억제제 유)는 여전히 비어 있고, 이 문헌으로도 채울 수 없다**(§5).
   채우려면 코드 주석(R8)이 요구한 그대로 — 억제제 농도 2수준 × pH 골 양쪽 3점 이상 스윕이
   한 표에 있어야 한다. 이 요건을 **미검색 항목**으로 남긴다.
3. **held-out ρ=0이 반드시 모델 결함은 아니다.** 모델이 게이트로 "모른다"를 선언한 구간을
   채점하면 ρ는 0 근처로 수렴한다. 백테스트 해석 시 **예측값이 조건 간 동일한지를 먼저 봐야**
   하며(`phm2016`에 이미 같은 경보가 붙어 있다), 동일하면 성능이 아니라 배선/게이트를 본다.

## 8. 한계·미검증

- **미검증**: Cabot 5001의 억제제 함유 여부·농도(상용 비공개). §5-1의 근거.
- **미검증**: H₂O₂ 농도를 원문은 vol%로 적었고 우리 키는 wt%다. 3.5 wt% H₂O₂ 수용액 밀도
  ≈1.01 g/mL라 차이 <1 %로 보아 그대로 대입했다 — **근사임을 명시**한다.
- **미검증**: 웨이퍼가 TWI용 두꺼운 전해도금 Cu(4인치)라 일반 다마신 Cu CMP와 절대 MRR
  수준이 다르다(최대 2908 Å/min). 계통편향 0.17배의 일부는 여기서 온다 — **순위 전용**.
- 원문 보정 R²=0.69로 반복 산포가 작지 않다(저자 스스로 "higher values are desired"라고 적었다).
  4점은 각각 3반복 평균이지만 표준편차는 인쇄되지 않았다 — **불확도 미확보**.
