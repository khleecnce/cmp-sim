## 4. Hill n=4.62 반증 시도 — 프로파일 SSE 분석

기존 노트 §5.4는 산화막·질화막을 **각각** 회귀했다고 서술하고, n이 "사실상 같다"(4.620 vs
4.623)는 것을 "같은 흡착 기구"의 증거로 든다. 이 주장을 직접 검증했다 — n을 고정하고 (K,k)만
재적합하는 프로파일 SSE를 두 막질 각각에 대해 독립적으로 그렸다(scipy `curve_fit`,
상대오차 가중, §6 verify).

**산화막 — n이 식별되지 않는다:**

| n(고정) | K | k | SSE |
|---|---|---|---|
| 3 | 0.402 | 50(경계) | 0.01605 |
| 4 | 0.971 | 6.08 | 0.01297 |
| **4.62** | **1.280** | **3.07** | **0.01342** |
| 8 | 1.832 | 1.70 | 0.01420 |
| 20 | 2.213 | 1.62 | 0.01428 |

n=4에서 n=20까지 SSE는 0.01297→0.01428, **10% 이내에서 사실상 평평**하다. n=4.62를 골라야
할 산화막 자체의 근거가 없다 — 데이터가 n=4를 선호하는 것도 n=20을 선호하는 것도 배제하지
못한다.

**질화막 — n에 진짜(얕지만 실재하는) 최소가 있다:**

| n(고정) | K | k | SSE |
|---|---|---|---|
| 1 | 13.53 | 3.99 | 1.357 |
| 3 | 14.20 | 3.46 | 0.582 |
| **4.62** | **14.03** | **3.40** | **0.461**(최소) |
| 8 | 14.36 | 3.31 | 0.684 |
| 20 | 15.91 | 3.26 | 1.109 |

질화막은 n=1(단일자리 Langmuir)보다 n≈4.6에서 SSE가 **3배 낮다** — 협동 흡착(n>1) 자체는
데이터가 실제로 지지한다. 그리고 n=20에서 다시 SSE가 2.4배로 악화된다 — 진짜 U자 최소.

**결론 — n=4.62는 질화막 브랜치가 정하고, 산화막은 따라간다.** 산화막·질화막을 **공유 n**
으로 동시 최소제곱(joint fit)하면:

```
K_ox=1.283, K_ni=14.03, n=4.627, k_ox=3.06, k_ni=3.40  (총 SSE=0.474, §6 verify)
```

이는 기존 노트의 값(1.2949 / 14.02 / 4.62 / 3.00 / 3.40)과 사실상 동일하다 — 즉 기존
노트의 절차는 (서술과 달리) **독립적 별도 회귀 두 번**이 아니라 **n을 공유한 결합 회귀**였을
가능성이 매우 높다. 결합 회귀의 총 SSE 0.474 중 질화막 몫이 0.461(97%)이다 — n은 사실상
전적으로 질화막 데이터가 결정하고, 산화막은 그 n을 받아도 거부할 근거가 없을 뿐이다.

**이것이 "n=4.62는 소수점 역산의 아티팩트인가"에 대한 답이다**: 완전한 아티팩트는 아니다
(질화막 쪽은 n>1을 실제로 요구하고, n≈4.6 근방에서 진짜 최소를 가진다). 그러나 "산화막과
질화막이 독립적으로 같은 n에 도달했다 = 같은 흡착 기구의 증거"라는 기존 노트의 해석은
**성립하지 않는다** — 산화막은 n을 독립적으로 결정할 정보가 없으므로 질화막과 "우연히 같다"는
서술 자체가 회귀 절차의 산물이다. `shield_hill_n`(산화막 값, sti_ceria.yaml이 실제로 쓰는
값)은 **산화막 자체 데이터가 아니라 질화막 데이터에 기댄 값**이라는 점이 이 노트의 핵심
추가 발견이다.

## 5. 등급 판정

세 상수를 EVIDENCE-RULES 서열(E1~E6)로 개별 판정한다:

- **`shield_langmuir_K`(1.2949)**: 같은 계(세리아 슬러리 + 세리아 연마 대상 SiO₂/Si₃N₄,
  Park 2003) 실측 그래프의 폐형식 유도값. K는 n에 강하게 얽혀 있다(n=4→K=0.97,
  n=20→K=2.21, §4) — **K 단독으로는 식별 안 됨**. (K,n) 쌍 전체로서만 곡선 형태를 나타낸다.
  → **E3(교란 있는 실측 기반 유도)** — 실측이지만 파라미터 개별 식별 불가라는 교란이 있다.
- **`shield_hill_n`(4.62)**: §4가 보였듯 산화막 단독으로는 비식별(E6에 가까움), 그러나
  결합 회귀 체계 안에서는 질화막 데이터가 실재하는 최소로 뒷받침한다(E3). **전체로는 E3**로
  본다 — n 자체가 허구는 아니지만, "산화막 자체의 협동성"이라는 물리적 의미 부여는
  근거가 약하다(순수 곡선-형태 파라미터로만 취급해야 한다는 기존 노트 §9-⑦의 입장이
  이 노트로 강화된다).
- **`shield_strength_k`(3.0)**: 기존 노트 §5.5가 이미 자백한 대로 산화막 SSE 프로파일이
  평평해(0.01297→0.01428, n=4~20) k 하한(≥1.62)만 있고 점추정은 불가능하다. 이 노트의
  §4 재현이 **독립적으로 그 자백을 확인**한다. → **E3~E4 경계** (같은 계 실측이나 사실상
  임의 선택).

**세 상수가 서로 다른 등급이 아니라 셋 다 "같은 계 실측 + 개별 비식별"이라는 동일 구조의
E3다.** 과제 규칙("셋이 다른 등급이면 가장 낮은 것이 칸을 막는다")은 이 경우 적용 대상이
아니다 — 셋이 이미 같은 등급으로 수렴한다.

**판정: confidence=`estimated` 유지, 승격하지 않는다.** 근거:
1. 1차 출처는 확인됐고 그림 판독은 재현 가능하다(§2, §3) — 그러나 confidence 승격 기준은
   "그림을 잘 읽었는가"가 아니라 "파라미터가 데이터로부터 개별 식별되는가"다. §4가 보인
   대로 산화막 (K,n,k) 셋 다 서로 얽혀 하나의 곡선-형태로만 식별된다.
2. `literature`로 승격하려면 최소한 "이 세 수치가 이 계에서 독립적으로 재현 가능한 물리
   상수"라는 근거가 필요한데, 반증 시도(§4)가 정확히 그 반대(n은 질화막에 얹혀가는 값,
   k는 하한만 있는 자유 파라미터)를 보였다.
3. 다만 이 노트는 estimated를 **하향(E6/채택금지)하지도 않는다** — E6은 "추정, 근거 없음"
   인데 이 값들은 원문 9점 실측을 그림 판독+회귀로 재현한 것이고(§3 표, 기존 노트 §8
   verify PASS), 문헌이 명시한 4개 텍스트 정박점과 독립적으로 일치한다(§8 [A]). 이는
   순수 추측보다는 명백히 강하다.

**요컨대 estimated는 원래도 정확한 라벨이었고, 이 노트는 "왜 정확한지"를 한 단계 더
근거 있게 만든다** — 특히 "n=4.62가 두 막질에서 독립적으로 일치해 물리적 의미가 있다"는
기존 노트 §5.4의 해석적 주장 하나는 이 노트로 **반증됐다**(§4). 그 반증은 confidence
레이블 자체를 바꾸지는 않지만, 이 레이블이 정직하다는 것을 강화한다.

## 6. verify 블록

```python verify
"""ψ 흡착 보호 3상수(shield_langmuir_K/hill_n/strength_k) — Park 2003 1차 출처 재대조.

이 블록이 지키는 것:
  ① 독립 디지타이징이 기존 노트 표(OX_MEAS/NI_MEAS)를 재현
  ② 산화막 n-프로파일이 평평함(비식별) — n=4~20에서 SSE 변화 <15%
  ③ 질화막 n-프로파일에 진짜 최소가 있음(n=1, n=20 모두 n=4.62보다 유의미하게 나쁨)
  ④ 공유-n 결합회귀가 sti_ceria.yaml 게시값(K=1.2949, n=4.62, k=3.00)을 재현
"""
import numpy as np
from scipy.optimize import curve_fit, least_squares

C  = np.array([0.00,0.02,0.04,0.06,0.08,0.10,0.20,0.40,0.80])
OX = np.array([3850,3800,3730,3680,3660,3650,3590,3380,760.0])  # 독립 재판독, 기존 노트와 일치
NI = np.array([800,735,660,315,80,60,50,35,20.0])               # 독립 재판독, 기존 노트와 일치

def theta(Cv, K, n):
    x = np.where(Cv > 0, (K * Cv) ** n, 0.0)
    return x / (1.0 + x)

def sse_profile(Cd, Yd, n_fix, p0):
    def f(Cv, K, k):
        return Yd[0] * np.exp(-k * theta(Cv, K, n_fix))
    popt, _ = curve_fit(f, Cd, Yd, p0=p0, sigma=Yd, maxfev=20000,
                         bounds=([1e-3, 0.05], [1000, 50]))
    resid = (f(Cd, *popt) - Yd) / Yd
    return float(np.sum(resid ** 2)), popt

# ① 독립 디지타이징이 원문 텍스트 정박점을 재현 (그림과 별개로 원문이 '텍스트로' 명시)
assert abs(OX[0] / NI[0] - 4.8) < 0.05                       # 무첨가 선택비 4.8
assert abs(OX[-1] / OX[0] - 0.20) < 0.02                     # 0.8 wt%에서 산화막 1/5
sel_04_idx = list(C).index(0.40)
# Fig.3 마커만으로 선택비 재현(회귀 없이) — 원문 '>70'과 같은 방향
crude_sel_04 = OX[sel_04_idx] / NI[sel_04_idx]
assert crude_sel_04 > 60, crude_sel_04   # 마커 판독 해상도 한계로 원문 '>70'에 근접(과소평가 방향)

# ② 산화막 n-프로파일: n=4~20 SSE 변화가 15% 미만 = 비식별
sse_ox_4,  _ = sse_profile(C, OX, 4.0,  [1.0, 5.0])
sse_ox_20, _ = sse_profile(C, OX, 20.0, [2.0, 1.6])
rel_change_ox = abs(sse_ox_20 - sse_ox_4) / sse_ox_4
assert rel_change_ox < 0.15, f"산화막 SSE 변화 {rel_change_ox:.1%} (예상보다 큼 -> n이 식별될 수도)"

# ③ 질화막 n-프로파일: n=4.62가 n=1, n=20보다 유의미하게 낫다(진짜 최소)
sse_ni_1,    _ = sse_profile(C, NI, 1.0,  [13.0, 4.0])
sse_ni_462,  _ = sse_profile(C, NI, 4.62, [14.0, 3.4])
sse_ni_20,   _ = sse_profile(C, NI, 20.0, [15.0, 3.3])
assert sse_ni_1   > 2.5 * sse_ni_462, (sse_ni_1, sse_ni_462)
assert sse_ni_20  > 2.0 * sse_ni_462, (sse_ni_20, sse_ni_462)

# ④ 산화막은 n=4.62 근방에서 이미 평평 -> n=4가 n=4.62보다 SSE가 살짝 낮아도 됨(비식별의 정의)
sse_ox_462, _ = sse_profile(C, OX, 4.62, [1.3, 3.0])
assert sse_ox_4 <= sse_ox_462 <= sse_ox_20 * 1.05  # 평평한 골짜기 안에 4.62가 들어있을 뿐

# ⑤ 공유-n 결합회귀가 sti_ceria.yaml 게시값을 재현
def resid_all(params):
    K_o, K_n, n, k_o, k_n = params
    ox_pred = OX[0] * np.exp(-k_o * theta(C, K_o, n))
    ni_pred = NI[0] * np.exp(-k_n * theta(C, K_n, n))
    return np.concatenate([(ox_pred - OX) / OX, (ni_pred - NI) / NI])

res = least_squares(resid_all, x0=[1.3, 14.0, 4.6, 3.0, 3.4],
                     bounds=([1e-3, 1e-3, 0.5, 0.05, 0.05], [100, 1000, 30, 50, 50]))
K_ox, K_ni, n_shared, k_ox, k_ni = res.x

YAML_K, YAML_N, YAML_K_STRENGTH = 1.2949, 4.62, 3.00
assert abs(K_ox - YAML_K) / YAML_K < 0.02, K_ox
assert abs(n_shared - YAML_N) / YAML_N < 0.02, n_shared
assert abs(k_ox - YAML_K_STRENGTH) / YAML_K_STRENGTH < 0.03, k_ox

# 결합회귀 총 SSE 중 질화막이 지배(>90%) -> n은 질화막이 결정한다는 §4 주장의 수치적 근거
total_sse = float(np.sum(res.fun ** 2))
ni_sse = float(np.sum(res.fun[len(C):] ** 2))
assert ni_sse / total_sse > 0.90, ni_sse / total_sse

print("PASS — 독립 디지타이징 재현, 산화막 n 비식별(15% 이내 평평), "
      "질화막 n 진짜 최소, 결합회귀가 yaml 값 재현(오차<2~3%), "
      f"질화막이 총SSE의 {ni_sse/total_sse:.0%} 차지")
```

**정량 재현 요약**: 독립 디지타이징은 기존 노트 9점 표와 전 구간 일치했다. 산화막 단독
n-프로파일은 n=4→20 구간 SSE 변화 <15%로 사실상 평평(비식별). 질화막 단독 n-프로파일은
n=4.62 근방에 진짜 최소가 있다(n=1 대비 2.5배 이상, n=20 대비 2배 이상 낮은 SSE). 공유-n
결합회귀는 `sti_ceria.yaml` 게시값(K=1.2949, n=4.62, k=3.00)을 오차 2~3% 이내로 재현했고,
그 결합회귀 총 SSE의 90% 이상이 질화막 몫이었다 — **n=4.62는 사실상 질화막 데이터가
정한다**는 §4 주장의 수치적 근거다.

## 7. 한계 / 정직성 표지

1. **판독은 마커 중심을 그림에서 다시 읽은 값이지 원문 수치표가 아니다.** 원문에 Fig.3
   데이터의 수치표는 없다(§2에서 전문 검색 확인) — 그림 판독은 이 문헌을 쓰는 한 피할 수
   없는 한계이고, 두 명(기존 노트 작성자, 이 노트 작성자)이 독립적으로 같은 값에 도달했다는
   점(§3)이 판독 신뢰도의 근거다.
2. **§4의 반증은 confidence를 낮추지 않았다** — 이미 estimated였다. 반증한 것은 "n=4.62가
   두 막질에서 독립적으로 같아서 물리적으로 의미 있다"는 **해석**이지, 폐형식 자체나
   문헌 재현성이 아니다. 폐형식(Hill+지수감쇠, §5.1~5.2 in 기존 노트)과 원문 재현은 여전히
   유효하다.
3. **PAA(폴리아크릴산) 한 종의 결과다.** §2에서 확인했듯 원문의 "음이온 계면활성제"는
   구체적으로 Mw=50000 폴리아크릴산이다. 다른 사슬길이·다른 음이온 첨가제로 일반화할 근거는
   기존 노트 §6(Dandu 2009 교차검증에서 4배 어긋남)이 이미 부정적으로 답했다 — 이 노트는
   그 결론을 바꾸지 않는다.
4. **결합회귀가 실제 원 저작 절차였는지는 추정이다.** 이 노트는 기존 노트가 "각 막질을
   개별 회귀했다"고 쓴 서술과, 결합회귀만이 정확히 게시값을 재현한다는 사실 사이의
   불일치를 지적했을 뿐, 원 저작자(이전 세션의 slurry-chemist)에게 직접 확인할 수는
   없다. 재현 실험(§6 ⑤)이 강한 정황 증거이지 자백 문서는 아니다.
