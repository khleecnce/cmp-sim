## 1. 왜 이 단원인가

판정#59 가 이 팩의 `abrasive` 정체성을 세리아→알루미나로 바로잡으면서, pH 분기
후보(세리아 IEP 창·실리카 정점·연화 폴백)가 **전부 다른 재료가 소유한 상속 계수**로
드러나 코드가 의도적으로 pH 항을 껐다. 그 결과 χ status 가 `unmodeled` 이 되고
완성 격자가 60→59 로 내려갔다(의도된 후퇴). 판정#59 는 이렇게 끝맺었다:

> "다음 회차가 찾아야 할 문헌이 정확해졌다 — **알루미나계 pH 계수 미확보**."

이번 회차 임무는 그 문헌을 구해 이 팩 **자기 재료계의** pH 계수를 세우는 것이다.

## 3. 새로 도출한 지식 — 왜 "지수 + 기계 하한"인가

pH 2→10 에서 MRR 이 **단조 감소**한다(Si면 3.56배, C면 2.94배). 방향이 실리카
정점형(pH 11 부근 최대)·세리아 IEP 창과 **반대**이므로 그 항들을 빌려 쓰면 부호가
틀린다. 메커니즘은 MnO4⁻ 의 산화력이다:

    MnO4⁻ + 4H⁺ + 3e⁻ → MnO2 + 2H2O ,  E = E° − (0.0788 V)·pH   (25 ℃, Nernst)

pH 가 오르면 구동 전위가 내려가고 산화막 생성 속도가 떨어진다. 구조는 W 산성역
항(`_ph_w_acidic_term`, Stojadinović 2016)과 같은 계열이다 — 다만 **순수 지수로는
안 맞는다**: pH 6~10 구간이 거의 평탄해서, 지수만 쓰면 pH 10 을 실측의 1/3 이하로
과소예측한다. 산화력이 꺼져도 **연마입자 압흔에 의한 기계 경로**가 남기 때문이다.
그래서 산화제 항(`_oxidizer_term`)의 기계 하한 φ 와 같은 형태를 pH 축에도 쓴다:

    g(pH) = φ + (1−φ)·exp(−k·(pH − 2)) ,   f(pH) = g(pH)/g(pH_ref)

Si면 5점 로그공간 최소자승 → **k = 0.546 /pH, φ = 0.268**(재현오차 −2.4~+2.6 %,
rms(log)=0.0171). C면은 k = 0.380, φ = 0.308 로 **더 완만**하다 — 면 방위가 형상까지
바꾼다는 뜻이지만, 이 팩의 기준 막질은 Si면이므로 Si면 값을 채택하고 면 방위 분기는
미모델링으로 남긴다.

φ=0.268 은 실측 pH10/pH2 비 **0.281** 과 같은 자릿수다(적합이 하한을 실측 끝점
근처로 끌어간 것이며, 독립 관측은 아니다 — 미검증).

## 4. 근거 충돌 판정 — Gong 2024 L25 의 pH 주효과는 "비유의"다

같은 팩의 held-out(Gong et al. 2024, doi:10.3390/ma17030679, L25)은 pH 2~6 에서
주변평균이 0.644/0.601/0.632/0.711/0.693 μm/h 로 **거의 평탄**하다. Chen 2020 은
같은 구간에서 2.9배 감소를 말한다 — 정면 충돌로 보인다.

L25 를 분산분석하면(이 노트 §6 verify 블록에서 실행):

| 인자 | SS | F(4,12) | p | η² |
|---|---|---|---|---|
| pH | 0.0410 | **1.041** | 0.426 | 0.143 |
| 산화제 | 0.0967 | 2.456 | 0.102 | 0.338 |
| 연마입자 | 0.0301 | 0.765 | 0.568 | 0.105 |

**세 인자 모두 α=0.05 에서 비유의**다(F crit = 3.259). 즉 Gong 의 "pH 효과가 작다"는
"pH 효과가 없다"가 아니라 **이 설계의 잔차(MSE=0.00984, 반복 없음)로는 구분할 수
없다**는 뜻이다. 반면 Chen 2020 은 pH만 바꾼 단일축 스윕에 조건당 3회 반복이 있고
스윙폭이 3.6배다.

EVIDENCE-RULES 서열 적용:
- 등급은 둘 다 E3(실측). 계 근접도도 비슷(4H vs 6H, 둘 다 알루미나+KMnO4 산성).
- **교란 통제**에서 Chen 이 이긴다: pH 단일축 × 반복 3회 vs 3인자 동시변동 × 무반복.
- **스윙폭**에서도 Chen 이 이긴다: 3.56배 vs 1.18배(주변평균 최대/최소).
- Gong 의 pH 범위는 2~6 으로 좁고, Chen 곡선의 급감 구간(2→6)이 Gong 의 전 범위다.
→ **Chen 2020 채택.** 단 Gong 의 null 을 지우지 않는다 — 아래 §5 에 실측 대가를 적는다.

두 지수를 평균내지 않았고(규칙 위반), 스코프도 쪼개지 않았다 — 같은 재료계·같은
pH 축이라 쪼갤 물리적 경계가 없기 때문이다. 충돌은 "한쪽이 검정력이 부족하다"로
해소되는 종류였다.

## 6. verify — 문헌값 재현

```python verify
import math

# ── (1) Chen 2020 Fig.1 판독의 자기검증: 눈금 간격으로 독립 결정한 스케일이
#        본문 인쇄 최대값을 재현하는가 (판독이 아니라 축 보정의 검산이다)
base = 192.38                                    # x축(0 nm/h) y좌표 [pt]
tops_si = [102.53, 145.10, 161.69, 165.93, 167.11]   # pH 2/4/6/8/10 막대 상단
tops_c  = [99.13, 129.63, 152.81, 155.81, 160.64]
s_si = 400.0 / 23.272      # Si면 주눈금 400 nm/h 당 23.272 pt
s_c  = 2000.0 / 29.090     # C면  주눈금 2000 nm/h 당 29.090 pt
si = [(base - t) * s_si for t in tops_si]
cf = [(base - t) * s_c  for t in tops_c]
assert abs(si[0] / 1554.0 - 1) < 0.01, si[0]     # 인쇄 Si면 최대 1554 nm/h
assert abs(cf[0] / 6412.0 - 1) < 0.01, cf[0]     # 인쇄 C면  최대 6412 nm/h

# 단조 감소 — 실리카 정점형·세리아 IEP 창과 부호가 반대라는 §3 의 근거
assert all(si[i] > si[i+1] for i in range(4))
assert all(cf[i] > cf[i+1] for i in range(4))
assert abs(si[0]/si[4] - 3.56) < 0.05            # Si면 pH2→10 3.56배
assert abs(cf[0]/cf[4] - 2.94) < 0.05            # C면 2.94배

# ── (2) 팩에 넣은 계수(k=0.546, φ=0.268)가 그 5점을 §3 이 적은 오차로 재현하는가
k, phi = 0.546, 0.268
g = lambda p: phi + (1 - phi) * math.exp(-k * (p - 2.0))
obs = [v / si[0] for v in si]
err = [g(p) / o - 1 for p, o in zip([2, 4, 6, 8, 10], obs)]
assert max(abs(e) for e in err) < 0.03, err      # -2.4~+2.6 % 이내
rms = math.sqrt(sum(math.log(g(p)/o)**2 for p, o in zip([2,4,6,8,10], obs)) / 5)
assert abs(rms - 0.0171) < 0.002, rms

# 순수 지수(φ=0)로는 pH 10 을 크게 과소예측한다 — §3 의 "하한이 필요하다"
plain = math.exp(-k * (10 - 2))
assert plain < obs[4] / 3, (plain, obs[4])

# ── (3) 이 항이 팩 기준 pH(2.3)에서 1.0 인가 (Kp 이중 계상 방지 계약)
ph_ref = 2.3
f = lambda p: g(p) / g(ph_ref)
assert abs(f(ph_ref) - 1.0) < 1e-12

# ── (4) §4 충돌 판정의 근거: Gong 2024 L25 의 pH 주효과는 비유의다
rows = [  # (pH, 산화제수준, 연마입자수준, MRR µm/h) — doi:10.3390/ma17030679 Table 2
 (2,1,1,0.5212),(2,2,3,0.7665),(2,3,5,0.7972),(2,4,2,0.4906),(2,5,4,0.6439),
 (3,1,5,0.5519),(3,2,2,0.4599),(3,3,4,0.7052),(3,4,1,0.6439),(3,5,3,0.6439),
 (4,1,4,0.4906),(4,2,1,0.7052),(4,3,3,0.5212),(4,4,5,0.7052),(4,5,2,0.7358),
 (5,1,3,0.5212),(5,2,5,0.7052),(5,3,2,0.7052),(5,4,4,0.8278),(5,5,1,0.7972),
 (6,1,2,0.5825),(6,2,4,0.7358),(6,3,1,0.6745),(6,4,3,0.7665),(6,5,5,0.7052)]
y = [r[3] for r in rows]
gm = sum(y) / len(y)
SST = sum((v - gm) ** 2 for v in y)
def ss(idx, levels):
    return sum(len([r for r in rows if r[idx] == L]) *
               (sum(r[3] for r in rows if r[idx] == L) /
                len([r for r in rows if r[idx] == L]) - gm) ** 2 for L in levels)
SS_ph  = ss(0, [2,3,4,5,6])
SS_ox  = ss(1, [1,2,3,4,5])
SS_abr = ss(2, [1,2,3,4,5])
MSE = (SST - SS_ph - SS_ox - SS_abr) / 12
F_ph, F_ox, F_abr = (SS_ph/4)/MSE, (SS_ox/4)/MSE, (SS_abr/4)/MSE
assert abs(F_ph - 1.041) < 0.01, F_ph
assert abs(F_ox - 2.456) < 0.01, F_ox
assert abs(F_abr - 0.765) < 0.01, F_abr
# F crit(4,12; 0.05) = 3.259 — 세 인자 전부 비유의
assert max(F_ph, F_ox, F_abr) < 3.259
# 원문 극차 R 은 산화제>pH>연마입자 인데, 유의성은 셋 다 없다 —
# "R 순위"와 "통계적 유의"는 다른 말이라는 것이 §4 판정의 핵심
assert F_ox > F_ph > F_abr
```

## 7. 한계 (정직 표기)

- 계수 출처가 **그래프 판독**이다. 축 보정은 인쇄 최대값으로 교차검증했지만 개별
  막대는 판독오차를 갖는다 — 등급 `estimated`, 승격하려면 인쇄 표를 가진 KMnO4
  pH 스윕이 필요하다(C2 로 남는다).
- Chen 2020 은 **6H-SiC**, 이 팩의 기준은 4H 계열이다. 두 폴리타입의 pH 응답이
  같은지는 확인 못 함 — 미검증.
- Chen 2020 의 KMnO4 는 **0.05 M**(≈0.79 wt%)인데 이 팩 기준 조성은 4 wt% 다.
  산화제 농도가 pH 곡선의 형상(k·φ)을 바꾸는지는 **미검증** — 두 축의 상호작용을
  독립으로 가정해 곱했다(`_f_chi` 가 이미 같은 경고를 남긴다).
- Si면 계수만 썼다. C면은 k=0.380·φ=0.308 로 다르며, 면 방위 분기는 미모델링.
- pH>10 · pH<2 는 외삽이다(코드가 notes 로 경고한다).
- 이 팩의 **산화제 축은 여전히 죽어 있다**(KMnO4 Langmuir 형상 미확보, 판정#50 의
  종 게이트가 H2O2 곡선 상속을 막고 있다). Gong L25 의 3축 중 이제 2축(pH·연마입자)이
  살아 있고 1축이 남는다 — 다음 회차 표적.
