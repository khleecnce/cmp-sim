# Reflexion LK 급 300 mm CMP 툴 — 전체 레이아웃 (3D 모델링용)

> 작성 2026-09-08 · 상태: 공개자료(특허 원문·제조사 페이지·보도자료) 확인 · **정확 치수는 제조사 비공개 → "추정" 표기**
> 목적: 3D 모델러가 이 문서만 보고 "툴 전체 → 폴리싱 스테이션 클릭 → 내부 / 클리닝 스테이션 클릭 → 내부"를 만들 수 있게 한다.
> 연결: [[cmp-tool-architecture]] (헤드/플래튼/링/컨디셔너 내부) · [[cmp-tool-endpoint-thermal-slurry-delivery]] (엔드포인트·슬러리 공급) · [[post-cmp-adsorption-cleaning-chemistry]] (클리닝 화학)

## 0. 결론 요약 (모델러용 한 줄)

**AMAT Reflexion LK = "3 플래튼 + 4 헤드 회전 캐러셀(정사각 배치) 폴리셔" + "수직 웨이퍼 직렬 4모듈 Desica 클리너" + "3 로드포트 팩토리 인터페이스"**, 세 블록이 한 직선(깊이 방향)으로 이어진 직육면체 툴. 웨이퍼는 FOUP → 드라이 로봇 → 웻 로봇 → 로드컵 → 헤드 → 플래튼 1→2→3 → 로드컵 → 웻 로봇 → 클리너(메가소닉→브러시→브러시→마랑고니 건조) → 드라이 로봇 → FOUP 순서로 흐른다. Dry-in/dry-out.

근거 확정 사항(표기 [확정]) vs 추정 사항(표기 [추정]) 을 §5 표에서 구분했다.

## 1. 평면 레이아웃

### 1.1 확정된 구조 (출처별)

| 사실 | 출처 |

## 2. 웨이퍼 흐름 (Dry-in / Dry-out)

```
FOUP(LP) ─DR→ [FI 트랜스퍼 플랫폼] ─WR(뒤집어 face-down)→ 입력버퍼 ─TS로봇→ 로드컵
   → (캐러셀 헤드가 로드컵 위에서 웨이퍼 흡착) → 캐러셀 90° → P1 (벌크 폴리시)
   → 90° → P2 (2단: 잔류/배리어 또는 계속) → 90° → P3 (3단/버프, 소프트 패드)
   → 90° → 로드컵 (헤드 릴리스, 웨이퍼·헤드 린스) ─TS로봇→ 출력버퍼
   ─WR(수직으로 회전)→ 클리너 IN(수직) → MEG → BB1 → BB2 → DRY(Marangoni, 수직 인양) → OUT(수평)
   ─DR→ (옵션: 인라인 메트롤로지) → FOUP
```

- 파이프라인: 캐러셀이 한 번 회전할 때 3 플래튼에서 3장이 동시에 폴리싱되고 TS 에서 1장이 교환된다 → 오버헤드는 스테이션 간 이동시간뿐[1]. 클리너도 5장 동시 이송, 모듈당 ≈30 s [7].
- 웨이퍼 자세: FI 수평 face-up → 폴리셔 수평 face-down → 클리너 **수직** → FI 수평 face-up [5][10].
- 폴리싱 모드: in-line(3 플래튼 같은 공정 1/3씩), multi-step(플래튼마다 다른 패드/슬러리), batch [1]. Cu 의 경우 P1 벌크 Cu, P2 잔류 Cu/배리어, P3 배리어/버프 [5][15].
- 청정도 차압: 로드/언로드부 양압(최고 청정) > 클리닝부 > 폴리싱부 음압(가장 오염) — Ebara 특허 명시[11]; AMAT 도 "환경 제어 인클로저"[5].

## 3. 폴리싱 스테이션 내부 (기존 [[cmp-tool-architecture]] 에 추가되는 것)

### 3.1 캐러셀 구조 (US 5,738,574 / 5,804,507)
```
              ┌──── 캐러셀 커버(4분할 쿼터 커버) ────┐
              │   ┌─── 십자형 지지판(Al, 두께≈6 cm) ──┐│
   헤드모터 ──┤   │  슬롯(방사형, 90° 간격 4개)        ││
              │   │   ▭═══════▭  ← 헤드 슬라이드가      ││
              │   │  안쪽↔바깥쪽 왕복(스윕)              ││
              └───┴──────────┬─────────────────────┘│
                       중앙 고정 포스트(902) ─ 베이스 내 모터가 판 전체를 회전
     헤드(110) ─ 드라이브 샤프트 ─ 회전커플링(높이 10.4 cm) ─ 하부 floater 5 mm 스트로크
```
- 지지판은 **십자형(팔 사이는 비어 있음)**, 팔 4개가 90°. 각 팔에 헤드 시스템 1개(헤드 + 헤드 회전 모터 + 반경 왕복 슬라이드)[1].
- 헤드 스윕: 슬롯 안에서 캐러셀 반지름 방향으로 왕복 → 패드 지름을 따라 이동. 스윕축은 패드 중심에 정렬[1].
- 폴리싱 중 헤드가 패드에서 들리는 높이 ≈ 6 mm(1/4 in)[1].
- 모델링: 캐러셀 판 지름 ≈ 2R + 0.4 ≈ **1.85 m** [추정], 판 상면 Z ≈ 1.75, 헤드 하면(패드 접촉) Z ≈ 1.00.

### 3.2 플래튼 간 간격
- 인접 플래튼 중심간 거리 = R·√2. R=0.72 → **1.02 m** ; 패드 Ø0.775 → 패드 가장자리 간 틈 ≈ **0.24 m** [추정, 기하학].
- 200 mm Mirra 실측: 플래튼 Ø 20 in(51 cm)[1]. 300 mm 는 AMAT 용 IC1000 패드가 **30.5 in(775 mm)** 규격으로 유통[16] → 플래튼 Ø ≈ 0.78~0.80 m.
- 플래튼 밑면에 쐐기형 림이 테이블 탑의 환형 드레인 채널 안에서 회전(슬러리 누출 방지 미로 씰)[1] → 테이블 탑에 각 플래튼 둘레 환형 홈을 모델링.

### 4.5 (비교) Ebara F-REX300 클리닝부 [11]
- 웨이퍼 **수평**. 1차 클리닝 = 롤 스펀지(PVA) 상·하 각 1개가 웨이퍼 위·아래에서 접촉, 웨이퍼는 스핀들 4개가 엣지를 잡고 회전[18]. 2차 = 펜슬 스펀지(스윙 암). 건조 = 로타고니(회전 + IPA).
- 1차·2차·건조 모듈이 **상하 2단**으로 쌓여 두 라인이 병렬(풋프린트 절감), 승강 로봇 2대가 사이의 트랜스퍼 챔버에 위치.
- 폴리싱부: 폴리싱 유닛 4개가 툴 장축 방향 일렬, 리니어 트랜스포터(TP1~4, TP5~7) 2대 + 스윙 트랜스포터, 톱링은 스윙 암 방식(캐러셀 아님).
→ 시뮬레이터에서 "AMAT 형(캐러셀·수직 클리너)" / "Ebara 형(일렬 테이블·수평 롤 클리너)" 두 프리셋으로 둘 수 있다.

## 6. 주의 사항 (정직성)
- AMAT 는 툴 풋프린트·플래튼 지름·캐러셀 반경을 공개하지 않는다. 위 R=0.72 m, 툴 2.2×5.5 m 는 **특허 배치 규칙 + 30.5 in 패드 + 사진 비율 + 로드포트 표준 피치**로 역산한 추정치이며 ±25 % 오차를 가정하라.
- 특허 도면 비율만 있는 것: 캐러셀 십자판 비율(팔 폭 ≈ 헤드 Ø), 클리너 모듈 피치 규칙(모듈 폭 ≤ X).
- Reflexion LK 자체 사진은 AMAT 서버 403 으로 확보 실패; LK Prime 사진(Wayback)으로 외관을 대신했다. LK 와 LK Prime 은 정면(로드포트 3개)·색상 동일 계열이나 LK Prime 이 더 길다(14 모듈).
- Mirra(200 mm) 특허의 "플래튼 사이 중간 세척 스테이션"은 Reflexion 도면(US 10,229,842 FIG.1)에는 없다 — 옵션으로만 모델링.

기하학적으로 유도한 값들을 계산으로 재현하고, 문헌/표준값과 대조한다.
(원 문헌은 정확 치수를 공개하지 않으므로 대조 대상은 "본문 표에 이미 적은 유도값"이며,
이는 어떤 도구도 공개되지 않은 실측치를 대신 확인해줄 수 없다는 뜻이다 — 아래 §6에 명시된
±25% 오차 가정은 그대로 유효하다. 이 블록의 목적은 "표에 적은 산수가 실제로 맞는지"를 담보하는 것.)

```python verify
import math

# 1) 인접 플래튼 중심간 거리 = R*sqrt(2), R=0.72 (본문 §3.2)
R = 0.72
center_dist = R * math.sqrt(2)
stated_center_dist = 1.02  # 본문 표 값
assert abs(center_dist - stated_center_dist) < 0.01, (center_dist, stated_center_dist)

# 2) 패드 가장자리 간 틈 = center_dist - 패드지름(0.775)
pad_dia = 0.775
gap = center_dist - pad_dia
stated_gap = 0.24
assert abs(gap - stated_gap) < 0.02, (gap, stated_gap)

# 3) IC1000 패드 규격 30.5 in -> m, 플래튼 지름 표기(0.78~0.80)와 대조
IN_TO_M = 0.0254
pad_dia_from_spec = 30.5 * IN_TO_M
assert abs(pad_dia_from_spec - 0.775) < 0.005, pad_dia_from_spec
# 문헌: 30.5 in = 0.7747 m -> 본문 0.775 m 표기와 1 mm 이내 일치 (근거 [16])

# 4) 로드포트 피치: SEMI E15.1 표준값 0.505 m (통용) vs 본문 좌표(0.55,1.06,1.56)
lp_pitch_stated = [1.06 - 0.55, 1.56 - 1.06]
semi_e15_1_pitch = 0.505  # 통용값(원문서 유료, §출처20 명시)
for p in lp_pitch_stated:
    assert abs(p - semi_e15_1_pitch) < 0.01, (p, semi_e15_1_pitch)

# 5) 캐러셀 판 지름 추정치 재현: 2R + 여유(0.4) = 1.85 표기와 대조 -> [추정] 표기 그대로 유지, 일치 확인만
carousel_dia_calc = 2 * R + 0.4
assert abs(carousel_dia_calc - 1.85) < 0.02, carousel_dia_calc

print("PASS: 5/5 기하 산출값이 본문 표기와 오차범위 내 일치")
print(f"center_dist={center_dist:.4f} gap={gap:.4f} pad_dia_from_spec={pad_dia_from_spec:.4f}")
```

**결론**: 표에 적은 유도값(플래튼 간격 1.02 m, 틈 0.24 m, 패드지름 0.775 m, 로드포트 피치 0.505 m,
캐러셀판 1.85 m)은 모두 본문에 명시한 산식(R√2, 30.5 in 환산, SEMI E15.1 통용 피치)으로 오차 1 cm/5 mm
이내로 재현된다. **단, R=0.72 m 자체와 "여유 0.4 m"는 AMAT 비공개 치수의 [추정]이라 이 검증은 "산수가
맞다"는 것만 보장하며 "실제 툴 치수와 일치한다"는 것은 보장하지 않는다** — §6 정직성 표기 유지.
